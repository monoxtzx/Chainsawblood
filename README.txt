Chainsaw Blood - web version for iPhone / iPad (and any phone browser)

1) Put every file in this folder on a static website with HTTPS, e.g. GitHub Pages:
   - create a public repository, upload these files, Settings -> Pages -> Deploy from branch (main, /root)
   - the game opens at https://<your-name>.github.io/<repo>/
2) On the iPhone, open that address in Safari
3) Tap Share -> "Add to Home Screen"
4) Start the game from the new home-screen icon: fullscreen, landscape, analog stick, works offline after the first visit
